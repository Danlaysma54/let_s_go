# Правила React-клиента

Web-клиент обслуживает кабинет площадки и административную панель. Публичное
мобильное приложение находится в `frontend/`.

## Структура

- `app/` - router, providers и layout.
- `features/` - вертикальные пользовательские сценарии.
- `entities/` - переиспользуемые предметные модели и UI.
- `shared/` - HTTP, конфигурация, дизайн-система и общие технические компоненты.

Не импортируйте внутренности одной feature из другой. Общий код выносится только
после появления реального повторного использования.

## Соглашения

- React Query хранит server state; локальное UI-состояние не дублирует его без
  причины.
- React Router задаёт маршруты и проверку доступа на уровне layout/route guard.
- Zod валидирует данные на внешней границе, пока типы клиента не генерируются из
  OpenAPI.
- Денежные значения остаются целыми minor units; форматирование выполняется
  только на уровне отображения.
- Роль в интерфейсе не является защитой: авторизацию каждой операции проверяет
  backend.

## Проверки

```bash
npm ci
npm run lint
npm run build
```

Не коммитьте `node_modules/` и `dist/`. Lock-файл обязателен и обновляется
вместе с зависимостями.
