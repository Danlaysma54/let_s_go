# Агентные сценарии

Этот каталог содержит переиспользуемые рабочие сценарии, а правила конкретных
компонентов находятся в их `AGENTS.md`.

- `playbooks/feature-delivery.md` - проведение функции от требования до
  проверенного результата.
- `playbooks/review.md` - проверка изменения перед передачей на ревью.

Сценарии не являются заменой продуктовой спецификации или ADR.
