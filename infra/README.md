# Инфраструктура

На первом этапе локальная инфраструктура описана корневыми `compose.yml` и
`compose.e2e.yml`.

Здесь появятся манифесты целевых окружений после выбора облака и способа
оркестрации. До этого момента не следует создавать фиктивные Kubernetes или
Terraform-конфигурации: они закрепят неподтверждённые решения о сети, секретах и
управляемых сервисах.
