# Правила API-контракта

- Редактируйте только `src/openapi.yaml`; производные клиенты и bundle должны генерироваться.
- Изменение контракта начинается с OpenAPI, затем реализуется в backend и клиентах.
- Все операции имеют стабильный `operationId` и документированные коды ошибок.
- Денежные поля имеют суффикс `Minor` и целочисленный тип; валюта передаётся отдельно по ISO 4217.
- Даты и время используют ISO 8601. Момент времени содержит смещение или `Z`.
- Новое несовместимое поведение требует новой версии API или согласованного периода миграции.
