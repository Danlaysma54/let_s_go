## Рабочие материалы

- `plans/` - активные планы реализации.
- `research/` - результаты исследований и прототипов.
- `backlog/` - технический долг, ещё не заведённый в трекере.
- `retro/` - выводы после инцидентов и крупных этапов.
- `roadmap/` - последовательность поставки крупных возможностей.
- `archive/` - устаревшие документы, исключённые из обычного поиска.
